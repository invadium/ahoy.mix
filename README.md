# Ahoy Mix - Collider.JAM Hello World Variations

Ever since the classic K&R C book, "Hello World" has remained the first program to try when learning a new programming language.

Collider.JAM doesn't restrict you to simple command-line interactions and provides a dynamic graphical environment instead.
Therefore, there are multiple ways to express "Hello World" in Collider.JAM. This repository collects some of them.

Each ```.mod``` folder contains a separate form of "hello". To run any of them, '''cd''' to the corresponding folder and launch Collider.JAM:

```
jam
```
